# نكام كوسميتيك (Nkam Cosmetics)

نظام تسيير محلات مستحضرات التجميل — إدارة المخزون، نقطة بيع، ملفات الزبائن، وتقارير المبيعات.
مبني بـ React + Vite + Tailwind CSS، مع تخزين محلي (localStorage) بلا حاجة لخادم.

## المميزات

- **لوحة تحكم** — ملخص مبيعات اليوم، تنبيهات المخزون المنخفض، وآخر العمليات.
- **نقطة بيع (POS)** — سلة تفاعلية، تحقق آلي من الكميات المتوفرة، تخفيضات (نسبة أو مبلغ ثابت).
- **مخزون** — إضافة/تعديل/حذف المنتجات، بحث وتصفية حسب الفئة، تصدير CSV.
- **زبائن** — سجل الزبائن مع تتبع عدد الزيارات وإجمالي الإنفاق، تصدير CSV.
- **تقارير** — تقرير مبيعات حسب الفترة، أكثر المنتجات مبيعًا، تصدير CSV (خاص بمالك المحل).
- **صلاحيات** — تمييز بين "مالك المحل" و"موظف" (واجهة فقط، بلا خادم).
- دعم كامل لـ RTL، تنقل بلوحة المفاتيح، وتباين ألوان يحقق معايير WCAG AA.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
npm run preview
```
